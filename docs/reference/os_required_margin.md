# Required Margin for Matched-Null Claims

Required Margin for Matched-Null Claims

## Usage

``` r
os_required_margin(mde80, w90, floor = 0.02)
```

## Arguments

- mde80:

  Minimum detectable effect at 80 percent power.

- w90:

  Width of the relevant 90 percent confidence interval.

- floor:

  Minimum floor margin.

## Value

Numeric required margin.
