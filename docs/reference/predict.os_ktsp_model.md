# Predict from a Top-k Oriented-Pair Panel Scorer

Predict from a Top-k Oriented-Pair Panel Scorer

## Usage

``` r
# S3 method for class 'os_ktsp_model'
predict(object, newdata, ...)
```

## Arguments

- object:

  An `os_ktsp_model` from `os_ktsp_fit`.

- newdata:

  Numeric matrix or data frame.

- ...:

  Unused.

## Value

Numeric vote fraction per sample.
