# Build a Terminal Gate Ledger

Build a Terminal Gate Ledger

## Usage

``` r
os_terminal_gate_ledger(gate_id, status, note = NULL)
```

## Arguments

- gate_id:

  Character vector of gate identifiers.

- status:

  Character vector of terminal statuses.

- note:

  Optional character vector of notes.

## Value

A data frame with fail-closed claim permissions.
