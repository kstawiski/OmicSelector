# Datasets included with OmicSelector

Datasets shipped with the package for examples, tutorials, and smoke
tests.

## Details

- `detectable_in_serum`: Reference list of detectable serum miRNA
  features.

- `miRNAselector_tutorial_balanced_dataset`: Balanced tutorial dataset
  (miRNA + labels).

- `miRNAselector_tutorial_balanced_mixed`: Balanced tutorial dataset
  with mixed features.

- `miRNAselector_tutorial_balanced_benchmark`: Balanced dataset prepared
  for benchmarking.

- `original_TCGA_data`: TCGA miRNA dataset with clinical labels. (Note:
  `orginal_TCGA_data` is retained for backward compatibility.)
