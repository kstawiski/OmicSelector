# OmicSelector_get_features_from_benchmark

Get which features are used by which method in the benchmark.

## Usage

``` r
OmicSelector_get_features_from_benchmark(
  benchmark_csv = "benchmark1578990441.6531.csv",
  method = "fcsig"
)
```

## Arguments

- benchmark_csv:

  Path to benchmark csv.

- method:

  Method of interest.

## Value

Vector of miRNAs.
