# Multi-Omics Support for OmicSelector 2.0

Functions and utilities for handling multi-omics data containers.
Designed to future-proof the API for Phase 4 integration.

## Details

This module provides: - Validation and normalization of multi-omics
input - Modality namespacing (e.g., rna::TP53, prot::TP53) - Late
integration support for ensemble models
