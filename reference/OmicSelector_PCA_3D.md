# OmicSelector_PCA_3D

Conduct PCA and create 3D scatterplot form first 3 components.

## Usage

``` r
OmicSelector_PCA_3D(ttpm_features, meta)
```

## Arguments

- ttpm_features:

  Normalizaed counts in \`ttpm\` format.

- meta:

  Factor of cases labels that should be visualized on biplot.

## Value

Plotly 3D object.
